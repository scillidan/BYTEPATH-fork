# GPi CASE 2 Controls

| Button | Action |
|---|---|
| D-pad | Navigate menus / Move in-game |
| A (fleft) | Confirm / Shoot |
| B (fright) | Up (menu) |
| X (fup) | (unused) |
| Y (fdown) | Down (menu) |
| Start | Start game / Confirm |
| Select | Escape / Back to menu |

## Console

All commands accessible via D-pad navigation, no keyboard needed:

1. Use D-pad to select a command (highlighted)
2. Press A or Start to execute
3. Press Select anytime to return to the command menu

## Installation

```sh
sudo apt install love
```

Then run:
